# Sedoelur-TeacherHub
Sedoelur TeacherHub adalah chatbot informasi untuk membantu siswa kelas XII-2 mengenal dan menemukan informasi mengenai guru mata pelajaran. Dengan tampilan yang sederhana dan interaktif, chatbot ini juga dapat membantu memberikan informasi seperti nama guru, mata pelajaran yang diampu, serta informasi terkait pembelajaran di kelas XII-2.
