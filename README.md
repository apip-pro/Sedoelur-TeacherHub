# Sedoelur-TeacherHub
Sedoelur TeacherHub adalah chatbot informasi untuk membantu siswa kelas XII-2 mengenal dan menemukan informasi mengenai guru mata pelajaran. Dengan tampilan yang sederhana dan interaktif, chatbot ini juga dapat membantu memberikan informasi seperti nama guru, mata pelajaran yang diampu, serta informasi terkait pembelajaran di kelas XII-2.

## 📌 Catatan Penting
* **Jadwal Piket Kelas:** Harap mematuhi jadwal piket harian demi kenyamanan proses belajar mengajar.
* **Pengumpulan Tugas:** Pengumpulan tugas mata pelajaran disesuaikan dengan instruksi masing-masing guru pengajar di atas.
* **Pembaruan Data:** Jika terdapat kesalahan penulisan nama atau informasi kontak, silakan ajukan *pull request* atau hubungi ketua kelas Xll-2.
